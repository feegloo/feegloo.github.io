Workflow Status

Lampka pokazuje stan workflow konkretnego commita. Śledzi build aplikacji oraz podpisanie i upload do App Store Connect. Po sukcesie, błędzie lub anulowaniu przestaje odpytywać.

Nie potrzebujesz osobnego konta, hasła ani konfiguracji Supabase. Wykorzystujemy istniejącą GitHub App vibeios.app (dawniej Signer).

  1. Zainstaluj vibeios.app na koncie lub organizacji z repo aplikacji. Jeśli już jest zainstalowana, sprawdź dostęp do repo. Wybierz wszystkie repozytoria, aby objąć również przyszłe, albo wybrane.
  2. W ChatGPT włącz Developer mode. Dodaj połączenie Workflow Status, wybierz bez uwierzytelniania / None i wklej adres MCP:

https://gwfdnwlhonszocjizrnl.supabase.co/functions/v1/workflow-status-widget/mcp

Włącz połączenie w rozmowie i poproś o status repozytorium oraz pełnego SHA commita. Każdy commit ma własną lampkę. Dwa linki pojawią się, gdy oba runy zostaną uruchomione.

Status i linki są dostępne bez logowania osobom znającym repo i pełny SHA. Widget nie udostępnia kodu, logów, artefaktów ani tokenów. Otwarcie prywatnego workflow na GitHubie nadal wymaga dostępu do repo.

Pełny tutorial ze screenami powstanie po sprawdzeniu połączenia w ChatGPT.
