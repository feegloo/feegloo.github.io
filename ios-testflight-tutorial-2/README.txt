TUTORIAL 02 - TESTFLIGHT

Rozpakuj całą paczkę i otwórz index.html w tym katalogu. Zachowaj sąsiedni folder ../tutoriale ze wspólnym CSS i JS.
Nie potrzeba npm ani kompilacji strony. Zakładki i kopiowanie prompta działają lokalnie; przy blokadzie schowka użyj zaznaczenia tekstu lub prompt.txt.
Prompt jest też w osobnym prompt.txt. Kod do repozytorium: code/.github/workflows/testflight.yml i code/scripts/prepare-testflight-export.py. Potrzebne są oba pliki. README nie zawiera żadnych prywatnych kluczy.
Kod zakłada XcodeGen, jedną aplikację, zgodne nazwy projektu i schematu. Rozszerzenia i Watch app wymagają dodatkowych profili i adaptacji.

Docelowa ścieżka: /ios-testflight-tutorial-2
Canonical/SEO: https://aleksanderfigiel.pl/ios-testflight-tutorial-2
Linki między częściami 1 i 2 działają lokalnie i na hostingu. Część 3 nie jest jeszcze dołączona. Przy zmianie domeny dostosuj canonical, og:url i JSON-LD.
Strona nie została opublikowana w internecie. To gotowy statyczny HTML.

Ilustracje: screeny z rozmowy. Dane na wybranych screenach zastąpiono fikcyjnymi przy użyciu edycji obrazu AI. Są to ilustracje poglądowe, nie niezmienione dowody wyglądu interfejsu. Pominięto wcześniejsze zastąpione warianty screenów i zrzuty starych kluczy/certyfikatów. Do paczki nie dołączono oryginałów z danymi osobistymi.
Wynik testu: upload z rolą API Developer i importowanym .p12, bez ręcznego Always Trust na Macu, zakończony instalacją i aktualizacją przez TestFlight. Windows/Linux opisano z dokumentacji, nie wykonano na tych systemach.
Processing 2-3 minuty to obserwacja, nie gwarancja. Limit 30 uploadów dziennie nie został potwierdzony w źródłach i nie jest podany jako obowiązujący fakt.

Wspólny wygląd i zachowanie: ../tutoriale/style.css oraz ../tutoriale/app.js. Edytuj je w jednym miejscu dla obu części. Resources zawiera wyłącznie zasoby tej części.
